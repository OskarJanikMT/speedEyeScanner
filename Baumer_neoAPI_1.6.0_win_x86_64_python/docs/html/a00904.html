Detailed Description

Camera update class which offers firmware update functionality The neoapi.Cam and neoapi.CamBase class deliver access to an instance of this class.

import neoapi
camera = neoapi.Cam() // create a camera object
camera.Connect() // connect to any device
camera.Utils.Update.EnableUpdateMode(True) // enable update mode (stops streaming)
camera.Utils.Update.SetUpdateFile("path-to-update-file") // set the update file
camera.Utils.Update.StartUpdate() // start the update -> will block untill finished
camera.Utils.Update.DisableUpdateMode() // disable update mode
image = camera.GetImage() // retrieve an image is now posssible again

◆ IsLegacyUpdateDevice()

"bool" neoapi.CamUpdate.IsLegacyUpdateDevice ( self)

Check is the device is a legacy update device.

The legacy update is only available for Baumer devices that do not support the generic update. Please note that the legacy update is not protected against power failure. Baumer cameras with the generic update have a secure update process and a rollback mechanism. The legacy update only checks the file contents to a limited extent; the file contents cannot be verified by the device. Generic updates for Baumer cameras are checked by the device to ensure that only valid files provided by Baumer are used.

Returns
True if the device is a legacy update device, otherwise false
Exceptions
NotConnectedExceptionNo device connected
NoAccessExceptionAccess to the device is not possible or internal error
