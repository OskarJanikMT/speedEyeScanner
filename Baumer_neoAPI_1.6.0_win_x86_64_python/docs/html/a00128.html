Detailed Description

Image post processing settings This class provides methods to configure image conversions.

You can pass an instance to the neoapi.Image.Convert method to apply the settings to an image convertion. USAGE:

image = neoapi.Image() # Create a Image object
settings = neoapi.ConverterSettings() # Create a ConverterSettings object
settings.SetSharpeningMode(neoapi.ConverterSettings.Sharpening_Adaptive) # Configure sharpening
settings.SetDebayerFormat("Mono8") # Set destination PixelFormat
image.Convert(settings) # Convert the image using the provided settings

◆ SetDebayerFormat()

"ConverterSettings" neoapi.ConverterSettings.SetDebayerFormat ( self,
"str" format )

Set the target PixelFormat for a conversion A camera can stream images in different formats.

However this might not be the format you need to work with the image data. You can use this setting to convert an image from one format to another. (e.g. convert BayerRG8 to BGR to work with the image data using OpenCV).

Note
Please see neoapi.PixelFormat for a list of possible formats
Not all input formats can be converted to all output formats. You can use the Image.GetAvailablePixelFormats() or the Image.PixelFormatIsAvailable() to check if a conversion is possible
