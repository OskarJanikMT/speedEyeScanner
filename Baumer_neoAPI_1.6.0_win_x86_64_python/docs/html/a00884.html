Detailed Description

Camera file management interface for reading, writing and managing files on GenICam devices This class provides methods to interact with files stored on GenICam compatible camera devices.

The CamFile interface allows you to transfer files between the host system and the camera's internal storage. Files are identified by name and accessed through standardized GenICam file access features. The class handles all low-level operations including chunked transfers for large files and proper error handling.

Note
File operations require the camera to support GenICam file access features (FileSelector, FileOpenMode, etc.). Not all cameras support file operations.
Warning
File operations can be time-intensive, especially for large files. Consider using appropriate timeouts and progress monitoring for your application. USAGE:
using namespace NeoAPI;
Cam camera;
camera.Connect();
// Access file interface through camera utilities
CamFile& file = camera.GetUtils().File;
// List available files
auto files = file.GetFileNames();
for (const auto& filename : files) {
std::cout << "File: " << filename << " (" << file.GetFileSize(filename) << " bytes)" << std::endl;
}
// Read file from camera to local storage
file.Read("UserSet1", "local_userset.bin");
// Write local file to camera
file.Write("calibration.xml", "CustomData1");

Delete the content of a file in the camera.

Clears the content of the specified file on the camera, effectively setting its size to zero. The file entry remains but contains no data.

Parameters
[in]camera_file_nameName of the file on the camera to clear
Returns
Reference to this CamFile object for method chaining
Exceptions
NotConnectedExceptionCamera is not connected
NoAccessExceptionCamera device cannot be accessed
FileAccessExceptionFile operation failed (file protected, etc.)
InvalidArgumentExceptionInvalid file name provided
Note
This operation clears file content but preserves the file entry. The file will still appear in GetFiles() but with zero size.
Warning
Deleted content cannot be recovered. Ensure you have backups of important data before calling this method.
